# What's New in VoidChat v0.8.0

### Новые возможности
- Фоновое подключение к серверу — приложение держит Socket.IO соединение активным в свернутом режиме через Android Foreground Service. Входящие звонки и сообщения доставляются без задержек, даже когда приложение не на экране.
- Системные уведомления о сообщениях — при получении сообщения в фоне показывается системное уведомление с текстом и именем отправителя. Тап по уведомлению открывает соответствующий чат через прямой native-to-JS канал.
- Умная кнопка «Обновить» — на экране настроек кнопка установки новой версии показывается только при наличии доступного релиза на GitHub. Проверка выполняется автоматически в фоне при старте приложения.

### Исправления
- Стабильное подключение при старте — таймаут подключения увеличен до 35 секунд (ранее 15), устранены ложные ошибки соединения. Ложные срабатывания ConnectionError больше не требуют ручного retry.
- Открытие чата по тапу на уведомлении — исправлена проблема, когда тап по системному уведомлению не открывал чат с нужным контактом. Реализован прямой канал из нативного кода в JS.
- CallKeep-интеграция для входящих звонков — системный экран входящего звонка отображается даже при свернутом приложении, что исключает пропущенные звонки.
- Audio routing при звонках — устранена гонка при переключении динамика (speaker/earpiece) в начале звонка.

### Улучшения
- Фоновый сервис регистрируется при подключении к серверу и останавливается при отключении, не расходуя ресурсы впустую.
- Уведомления используют два канала: `voidchat-background` (бесшумный, для поддержания сервиса) и `voidchat-messages` (со звуком и вибрацией для сообщений).
- Добавлены русскоязычные тексты уведомлений и названия каналов.
- Множество улучшений стабильности и производительности под капотом.
