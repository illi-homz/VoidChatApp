### 🔗 Стабильность соединения

- Исправлена проблема с потерей соединения при навигации — сокет больше не «отваливается» навсегда
- Автоматическое переподключение при возврате из фона (AppState)
- Статус соединения теперь отображается мгновенно (реактивный MobX)
- Серверный таймаут ping увеличен до 20 секунд — мобильные клиенты не теряют связь при кратковременных задержках

### 📞 Голосовые звонки

- **Динамик включён по умолчанию** — собеседник слышен сразу, без нажатия кнопки
- Звонок выдерживает обрывы сети до **10 секунд** (было 5с)
- Исправлена громкость на устройствах, где WebRTC использует музыкальный стрим
- Исправлен сброс speakerphone при старте звонка

### 🐛 Исправления

- Устранено ложное отображение статуса соединения (зелёный/красный маркер)
- Надёжная обработка ошибок подключения (Socket.IO сам управляет реконнектом)
