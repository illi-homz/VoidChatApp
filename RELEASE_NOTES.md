### 🗄 Миграция на SQLite

- **Вся история чатов теперь в SQLite** — AsyncStorage заменён на `@op-engineering/op-sqlite`. Данные не теряются, миграция происходит автоматически при первом запуске
- **Реактивные подписки** — контакты, сообщения, непрочитанные счётчики и история звонков обновляются мгновенно через SQLite update hooks
- **Авто-очистка** — старые сообщения автоматически удаляются (по количеству, по возрасту, по возрасту медиа)
- **27 новых интеграционных тестов** для DatabaseService
